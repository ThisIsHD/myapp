# Himadri's Portfolio


This is the source code for my personal portfolio website, built with Next.js, TypeScript, and Tailwind CSS. It features a modern, responsive, and animated design with a neon aesthetic to showcase my projects and skills as a creative developer.

## ✨ Key Features

-   **Interactive UI:** Smooth animations and transitions powered by Framer Motion.
-   **Dynamic Content:** Sections for About, Services, Projects, and an interactive Tech Stack showcase.
-   **Responsive Design:** Fully responsive layout for all devices, built with Tailwind CSS.
-   **Theme Toggling:** Switch between light, dark, and system default themes.
-   **Hero Section:** Features a multi-lingual typing animation to greet visitors.
-   **Project Showcase:** Detailed cards for each project, including descriptions, tech stacks, and links to live demos and GitHub repositories.

## 🛠️ Tech Stack

-   **Framework:** [Next.js](https://nextjs.org/) 14 (App Router)
-   **Language:** [TypeScript](https://www.typescriptlang.org/)
-   **Styling:** [Tailwind CSS](https://tailwindcss.com/)
-   **Animations:** [Framer Motion](https://www.framer.com/motion/)
-   **UI Components:** [Radix UI](https://www.radix-ui.com/) for icons, [Tippy.js](https://atomiks.github.io/tippyjs/) for tooltips
-   **Theming:** [next-themes](https://github.com/pacocoursey/next-themes)

## 📂 Project Structure

The codebase is organized following modern Next.js conventions:

```
.
├── app/                  # Next.js App Router pages and layouts
│   ├── Projects/         # Dedicated page for all projects
│   ├── layout.tsx        # Root layout
│   └── page.tsx          # Home page
├── components/           # Reusable React components
│   ├── About/
│   ├── Hero/
│   ├── Projects/
│   └── ui/               # General UI components (AnimatedButton, ThemeToggle)
├── lib/                  # Utility functions and animation variants
├── public/               # Static assets (images, resume)
└── ...                   # Configuration files (Next.js, Tailwind, etc.)
```

## 🚀 Getting Started

To run this project locally, follow these steps:

1.  **Clone the repository:**
    ```sh
    git clone https://github.com/ThisIsHD/myapp.git
    cd myapp
    ```

2.  **Install dependencies:**
    ```sh
    npm install
    ```

3.  **Run the development server:**
    ```sh
    npm run dev
    ```

4.  Open [http://localhost:3000](http://localhost:3000) in your browser to see the result.
